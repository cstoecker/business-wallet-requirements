# RES-universal-b2b: primary-source anchors for one slide, "same pattern in B2B and micro registers"

Date of work: 2026-10-04 (status date for all "status" cells). Primary sources only. No repo file edited.
Pattern per anchor: who writes | who reads | identifier | evidence object | integrity / signature requirement | what it triggers | silence on linked data / signatures.
Read states: full = the article/section was read as text; part = section read, rest of document not; fetch = summarising fetch tool only (re-check quotes); not read.
Method: EUR-Lex texts downloaded as XHTML from publications.europa.eu and read directly (quotes exact). A2A, DSP catalogue, CX-0152 read as text from the spec pages / repository. GLEIF pages via fetch tool.
Register IDs reused where they exist in `_data/graph/sources.yml`; new IDs are in `/tmp/review/RES-universal-b2b-new_sources.yml`.
Confidence rule: a statement marked "not found" means searched in the named text and absent, not that it is absent elsewhere.

## Slide fit (same pattern, five elements) and where it does not hold

| Domain | Who writes | Who reads | Identifier | Evidence object | Integrity requirement in the law or spec | Trigger |
|---|---|---|---|---|---|---|
| Battery passport | economic operator placing on market, or authorised operator (Art 77(4)) | public; notified bodies, market surveillance authorities, Commission; persons with legitimate interest (Art 77(2), Annex XIII) | QR code to unique identifier, ISO/IEC 15459 (Art 77(3)) | passport data, declaration of conformity (Annex XIII 1(r)), test reports (point 3) | "data authentication, reliability and integrity shall be ensured" (Art 78(g)); no scheme named | placing on market from 18.2.2027; re-use and repurposing hand-over (Art 77(7)) |
| ESPR DPP | per delegated act (Art 9(2)) | per delegated act; list in Art 11(1)(b) | persistent unique product identifier (Art 10(1)(a)) | data per Annex III and delegated act | same wording (Art 11(1)(g)) | market access (Art 9(1)); customs checks (Art 15) |
| CSDDD | company in scope | supervisory authority, claimants in court | none prescribed | documentation "including supporting evidence" (Art 5(4)) | none | supervision, civil liability; applies from 26.7.2029 |
| Catena-X catalogue | data provider | participants satisfying access policy | BPNL | Offer with access and usage policy | credential checks MUST (CX-0152 2.2) | negotiation, agreement, transfer |
| A2A card | agent provider | any client; authenticated clients (extended) | provider URL, card id | Agent Card, optional JWS | signing MAY; verification SHOULD | client selects agent and calls it |
| AI Act logs | the system (provider design) | provider, deployer, authority | none | event logs | none stated | post-market monitoring, risk reporting |

Where the pattern does not hold in primary text: (1) linked data is required by no EU instrument in this note (ESPR, Battery Regulation, CSDDD, AI Act, Data Act all silent); the only linked-data text is CIR 2026/1778 Art 12 (typed, resolvable links) and DCAT-AP metadata, and the DSP catalogue (JSON-LD contexts). (2) Signatures are required by none of the EU instruments; only A2A (optional JWS) and UNTP (MUST VC-JOSE-COSE) specify them. (3) Behavioural drift is not defined in any primary text found.

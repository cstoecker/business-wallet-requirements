# Project skills for developing the site

Skills live in `.claude/skills/<name>/SKILL.md` and are loaded by Claude Code when the repository is the working directory.

| Skill | Use |
|---|---|
| `ebw-site-build-preview` | Build, check, commit, push and publish the `gh-pages` preview |
| `ebw-add-requirements` | Research and import requirements from official sources, with categories and traceability |
| `ebw-requirements-review` | Fidelity, quality, priority and cluster review; the review worklist |
| `ebw-concept-article` | Write a concept article with sources, figures, FAQ and checks |
| `ebw-decision-page` | Derive and write architecture decision pages from clusters and research notes |
| `ebw-brand-review` | Review the site against the Spherity design system |
| `ebw-watch-triage` | Turn the weekly source-watch pull request into verified updates |

The design rules come from the `spherity-design` plugin (https://github.com/spherity/claude-plugins). The SEO, AEO and GEO rules come from `spherity-site-seo` (docs/04); the training-crawler decision stays with Legal.

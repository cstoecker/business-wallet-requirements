# Review submissions

Put filled review worksheets here (`ebw-review-worksheet-<name>.xlsx`, from the Downloads page of the site), on the branch you were given. The maintainer imports them with `python3 scripts/import_review_feedback.py FILE.xlsx` (dry run first, `--apply` after checking). Feedback is stored in `_data/review/feedback.yml` and driver confirmations in `_data/review/driver-confirmations.yml`.

See the sheet "How to review" in the worksheet for the steps.

req_id: EBW-LEG-010
title: Present only attributes necessary for the purpose
category: LEG
statement: When a wallet presents an attestation containing personal data, the wallet shall disclose only the attributes that are adequate, relevant and limited to what is necessary for the purpose stated by the relying party.
rationale: Data minimisation applies to each presentation, so the wallet must support attribute-level disclosure for representatives' personal data.

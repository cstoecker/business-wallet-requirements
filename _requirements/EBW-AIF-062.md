title: Data-space participants describe formats, vocabularies and code lists
category: AIF
statement: A participant in a data space that offers data or data services to other participants shall describe data structures, data formats, vocabularies, classification schemes, taxonomies and code lists, where available, in a publicly available and consistent manner.
rationale: Publicly described semantics enable AI-driven mapping of data between spaces; complements EBW-DAT-001 and EBW-DAT-002, which cover points (a) and (c).

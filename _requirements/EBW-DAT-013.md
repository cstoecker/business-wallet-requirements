req_id: EBW-DAT-013
title: Export of exportable data in machine-readable form on switching
category: DAT
statement: In switching between services of the same service type without published common specifications, the provider of data processing services shall, at the request of the customer, export all exportable data in a structured, commonly used and machine-readable format.
rationale: Where a wallet is offered as a cloud or software service, this is the portability duty; it mirrors the export function the proposal sets for wallets (to verify whether a wallet service is a data processing service in the Data Act sense).
